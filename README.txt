KING CLASSIC BARBERSHOP — BARBER STUDIO WEBSITE

FILES
- index.html: page content and structure
- style.css: styling, responsive layout, animations
- script.js: navigation, animated wave canvas, booking form and WhatsApp handoff
- price_calculator.cpp: optional C++ console example for calculating service prices

HOW TO OPEN
1. Extract barber_shop_website.zip.
2. Open the folder.
3. Open index.html in Chrome, Edge, Firefox, or another browser.
The site works on phones and laptops. Internet is needed for the online photos and optional Google Fonts.

IMPORTANT — WHATSAPP BOOKING
Open script.js and find:
const WHATSAPP_NUMBER = "255700000000";
Replace it with the real business number in international format without +, spaces or dashes.
Example format: 2557XXXXXXXX
The current number is only a placeholder. Do not publish until you change it.

EDIT BUSINESS DETAILS
- Change the shop name, prices, location and WhatsApp number to match your business.
- Update prices in index.html and price_calculator.cpp.
- Replace the location text with your actual address.
- Replace the online photos with your own shop photos if desired.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html, style.css, and script.js to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. When GitHub provides the live URL, share it with customers.

C++ NOTE
C++ is included as an optional price calculator example. Browsers do not execute C++ directly. The website front end uses HTML, CSS and JavaScript.
